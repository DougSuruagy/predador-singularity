## 🚀 Como Configurar (Quick Start)

1.  **Binance**:
    *   Crie uma chave API com permissões de **Futures** (se for operar alavancado).
    *   Deposite o capital inicial (Recomendado: R$ 100 em USDT).

2.  **Render (Hospedagem API)**:
    *   Conecte este repositório no Render.
    *   Adicione as Variáveis de Ambiente:
        *   `BINANCE_API_KEY`, `BINANCE_API_SECRET`
        *   `SUPABASE_URL`, `SUPABASE_KEY`

3.  **Sinais (TradingView)**:
    *   Configure seus alertas para disparar o Webhook: `https://seu-app-render.com/webhook`
    *   O Predator fará todo o resto de forma autônoma.
