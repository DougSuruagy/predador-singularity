# 🐋 POLYMARKET WHALE SNIPER v1.0 (BETA)

Este sistema é um braço auxiliar do ecossistema PREDADOR, operando sob a bandeira da **Sovereign Security**.

## 🎯 Objetivo
Monitorar e copiar "Baleias" (Traders de Elite) da Polymarket em tempo real, utilizando a **DeepMachine** para filtrar sinais de alta probabilidade.

## 🏗️ Arquitetura
- **Whale Radar**: Monitoramento via RPC Polygon.
- **Decision Engine**: Filtro neural de rentabilidade histórica.
- **Execution Core**: Conexão direta com Polymarket CLOB via API.

## 🚦 Requisitos Próximos
- [ ] Chave API Polymarket (Profile > Settings > API Keys)
- [ ] Chave RPC Polygon (Alchemy ou Infura)
- [ ] Wallet Dedicada (Polygon) com USDC.e saldo.
