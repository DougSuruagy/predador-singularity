# PREDATOR PROGRESS LOG

## Iteration v25.0 Bybit Sovereign
- **Status:** COMPLETED
- **Learnings:**
  - **Sovereign Architecture**: Purged all Binance legacy code. The system is now 100% hardcoded for **Bybit V5 Linear Perpetual** markets.
  - **Direct Driver Initialization**: Removed conditional exchange loading, speeding up boot time and reducing overhead.
  - **Symbol Normalization Hardened**: Integrated `bybit_normalize_symbol` everywhere to ensure zero-latency routing of TradingView signals.
  - **Namespace Consolidation**: Renamed core execution and session functions (e.g., `execute_bybit_order`, `maintain_sovereign_session`) to reflect the new architecture.
  - **UTA Compatibility**: Verified and adjusted balance fetching logic for Unified Trading Accounts.

## Iteration v24.1 Bybit Strike (Current)
- **Status:** COMPLETED
- **Learnings:**
  - Implemented **Global Symbol Normalizer**: `normalize_symbol` function automatically adapts tickers (`BTC/USDT` <-> `BTCUSDT`) based on the active Exchange ID. This prevents failures on Bybit V5 which rejects slashes.
  - Enhanced **Leverage Logic**: Added safeguards for Bybit's API which throws errors if leverage is already set, preventing unnecessary log spam.
  - Added **Boot Balance Check**: The system now prints the detected initial balance on startup, aiding in debugging connectivity.

## Iteration v24.0 Multi-Market Nexus
- **Status:** COMPLETED
- **Learnings:**
  - Implemented **Multi-Exchange Logic**. The system now supports dynamic switching between **Binance** (Futures) and **Bybit** (Linear/Unified) via `EXCHANGE_ID` environment variable.
  - This solves the critical blocker of Binance requiring Trusted IPs for API trading, as Bybit is more permissive with Cloud IPs (Render).
  - Codebase refactored to use generic `API_KEY` loading, ensuring agnosticism.

## Iteration v23.1 Liquidity Gatekeeper
- **Status:** COMPLETED
- **Learnings:**
  - Implemented **Liquidity Gatekeeper Protocol**: The system now starts in a locked state (`funding_locked=True`) and only unlocks `is_hunting` if the background scanner confirms a Binance USDT balance > $5.
  - Removed dangerous fallback simulation money ($20) from production logic. No money = No Trade.
  - Webhook signals are explicitly rejected with `NO_FUEL` reason if funds are insufficient.
